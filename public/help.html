How it works

DecisionPorter reads new support tickets from Gorgias every 15 minutes. When a customer has an open complaint, it coordinates your other apps so they don't work against each other:

  1. Hold review requests. The customer gets the Shopify tag dp-hold-review, which Judge.me can be told to skip. The tag comes off when the ticket closes, or after the maximum hold (14 days by default), so requests are delayed, never cancelled.
  2. Pause promotional emails. The customer's Klaviyo profile gets dp_open_complaint = true while the complaint is open.
  3. Flag problem products. Repeated sizing or quality complaints about one product tag it dp-sizing-watch or dp-quality-watch in Shopify.
  4. Put your best customers first. Tickets from customers above your spend threshold get the Gorgias tag decisionporter-vip.
Shadow mode first. Every store starts in shadow mode: DecisionPorter only writes down what it would do in the Decision log and changes nothing. Watch the log for a week or two, then switch to live mode when you trust it.

Only Gorgias is required. Connect the others to turn on the rules that use them.

1. Connect Gorgias (required)

  1. In Gorgias, open Settings → REST API.
  2. Copy your API key. The same page shows the account email to use with it.
  3. In DecisionPorter, under Connect Gorgias, enter your Gorgias subdomain (the part before .gorgias.com), that email, and the API key. Click Connect.
  4. For the VIP rule: in Gorgias, create a view (or a rule) that shows tickets tagged decisionporter-vip first, so your team sees them at the top.

2. Connect Judge.me (review holds)

  1. In Judge.me, open Settings → Integrations → View API tokens and copy the Private API token.
  2. Paste it under Connect Judge.me and click Connect. Your store is filled in automatically.
  3. Important: in Judge.me's review request settings, add the customer tag dp-hold-review to the tags whose customers should not receive review requests. Without this step DecisionPorter can tag customers, but Judge.me will still email them.

3. Connect Klaviyo (pause promotions, win-back)

  1. In Klaviyo, open Settings → API Keys and create a private API key with full access to Profiles and Lists. DecisionPorter only updates profiles that already exist; it never creates new ones.
  2. Create (or pick) a list for win-back, open it, and copy its list ID from the list's page.
  3. Paste the key and list ID under Connect Klaviyo and click Connect.
  4. Important: in each promotional flow, add a profile filter: dp_open_complaint is not true. This is what actually pauses promotions for unhappy customers.

4. Connect Inventory Planner (optional)

Inventory Planner is read-only. When a product is flagged for sizing or quality complaints, DecisionPorter shows Inventory Planner's reorder recommendation next to it, so you can check before reordering.

  1. In Inventory Planner, open Account → Settings → API.
  2. Copy the API key and Account ID, paste them under Connect Inventory Planner, and click Connect.

Going live

  1. Check the Decision log. Each line shows the customer or product, the rule, and the action DecisionPorter would take.
  2. Under Rules, turn off any rule you don't want and adjust the VIP threshold, the maximum hold days and the product complaint count.
  3. Choose a paid plan under Plans. Shopify bills it on your Shopify invoice after a 14-day free trial, and you can switch plans at any time. Each plan covers a number of new Gorgias tickets per 30 days: Starter 300, Growth 2,000, Scale 5,000. The dashboard shows your usage. If you go over, new decisions are logged in shadow mode (nothing is lost, and holds already applied are still released) until you upgrade or usage drops.
  4. Tick Live mode and click Save rules. You can switch back to shadow mode at any time.

Questions

What happens if I uninstall?

DecisionPorter stops immediately and deletes your store's data, including your saved keys. Tags already applied stay in your apps; you can remove them by searching for the tag names above.

What customer data do you keep?

Only what the rules need (email, ticket IDs, the decision taken), kept for 90 days. See the Privacy Policy.

A connection says the key is invalid.

Create a fresh key in that app, check it has the access listed above, and connect again. Keys are stored encrypted and never shown back to you.
